# louro

louro lets any coding agent with a shell act as an IRC bot. An operator starts a daemon that holds the connection; the agent runs `louro wait` and `louro send` in a loop. It is built on [papo](https://github.com/luizribeiro/papo).

Work in progress. Nothing here is usable yet.
